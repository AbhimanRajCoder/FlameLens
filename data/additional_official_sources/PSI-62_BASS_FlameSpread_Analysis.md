# Additional source: PSI-62 — Concurrent Flame Spread Modeling using Flamelet Generated Manifolds with BASS/BASS-II comparison

**Category:** Flame spread / derived analysis and physics-model comparison.  
**Official NASA PSI record:** https://psi.nasa.gov/physci/repo/data/investigations/PSI-62  
**DOI:** 10.60555/e9xp-ex83  
**Bundle status:** Official metadata reviewed; no PSI-62 analysis files are included in this pack.

## Why add it

NASA describes work combining high-resolution computational modelling with experimental validation on BASS geometries. Experimental BASS/BASS-II imagery was post-processed using two-color tomography to reconstruct soot and temperature fields. Reported evaluation quantities include flame geometry, temperature distribution, soot volume fraction and flame spread rate.

## Data to retrieve

- Two-color tomography-derived soot and temperature fields.
- Flame geometry and flame-front measurements.
- Flame spread-rate outputs with time interval and measurement uncertainty.
- Sample geometry/material metadata and mapping to original BASS/BASS-II tests.
- Simulation input decks, solver outputs and model-validation/error summaries, if released.

## Model use and restrictions

This source may help repair the missing target problem for the flame-spread track. It is a ground analysis/modeling investigation based on existing BASS/BASS-II evidence. It is not a new independent microgravity flight dataset. Use derived outputs only when they are traceable to the originating PSI-25/PSI-26 record and the relevant measurement method is documented.
