# Additional source: PSI-101 — SAME-R

**Category:** Smoke / aerosol detection.  
**Official NASA PSI record:** https://psi.nasa.gov/physci/repo/data/investigations/PSI-101  
**DOI:** 10.60555/2np7-jv14  
**Bundle status:** Official metadata reviewed; raw/analysed files are not included in this pack.

## Why add it

SAME-R is a reflight related to PSI-102 SAME. NASA describes a goal of quantifying low-gravity smoke-particle sizes and relating distributions to smoke generation and transport. The NASA record describes 66 flight test points and modified diagnostics, including M-pass, after contamination issues affected the original SAME TEM grids.

## Data products to retrieve

- Reduced particle size distributions and associated method/uncertainty.
- Particle morphology / microscopy images, contamination flags and provenance.
- Source sample and heating conditions.
- Airflow, test timing and transport conditions.
- Diagnostic hardware metadata and M-pass/DustTrak/ionization detector response data, where actually available.
- Final report and flight-versus-ground comparison results.

## Model use

Treat SAME-R as a distinct detection evidence branch from SAME. The instrumentation and test protocol changed; compare them explicitly instead of flattening both sources into one unlabeled table. Particle measurements do not equal detector alarm performance unless paired sensor-response data are present.
