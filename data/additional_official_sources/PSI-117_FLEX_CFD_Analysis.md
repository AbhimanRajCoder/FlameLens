# Additional source: PSI-117 — Effect of External Thermo-Convective Perturbation on Cool Flame Dynamics

**Category:** Extinction physics / simulation and interpretation.  
**Official NASA PSI catalogue:** https://psi.nasa.gov/physci/repo/search?data_source=psi&data_type=investigation  
**Bundle status:** Catalogue metadata reviewed; exact source-file record should be located by the investigation title in PSI before download.

NASA's PSI catalogue describes a ground CFD analysis using FLEX flight data to study n-alkane droplet cool flames under externally imposed thermal and convective perturbations, using OpenFOAM and low-temperature combustion chemistry.

## Appropriate use

- A physics/simulation comparison for the FLEX extinction and cool-flame branch.
- Help interpret why a visible flame can disappear while low-temperature chemical activity continues.
- Identify candidate physical variables, model assumptions and simulation-to-experiment discrepancies.

## Restrictions

This is a ground computational analysis using existing FLEX data, not an independent experimental dataset. Do not append simulation outputs as new NASA flight observations. Preserve simulator provenance and validate simulation-to-experiment discrepancy separately.
